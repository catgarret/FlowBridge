# Flow Bridge 0.1.4

## English

- Replaces minimum-brightness-only behavior with scrcpy physical-screen-off mode.
- Keeps DEX and phone-mirroring video active on the Mac while the Galaxy panel is off.
- Wakes the Galaxy and restores its previous brightness and auto-brightness mode when the session ends or the option is disabled.

## 한국어

- 밝기만 최저로 낮추던 동작을 scrcpy 실물 화면 끄기 방식으로 교체했습니다.
- Galaxy 패널이 꺼진 동안에도 Mac의 DEX·휴대폰 미러링 영상은 유지됩니다.
- 세션 종료 또는 옵션 해제 시 Galaxy를 깨우고 기존 밝기와 자동 밝기 모드를 복원합니다.
