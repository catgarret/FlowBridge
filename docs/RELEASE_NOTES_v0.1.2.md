# Flow Bridge 0.1.2

## English

- Shows friendly Galaxy app names instead of package identifiers in Mac notifications.
- Adds cached Galaxy app icons as notification attachments where macOS supports them.
- Adds persistent per-app Mac notification controls in Notification Settings and live Galaxy notification rows.
- Shows SMS sending progress, blocks duplicate sends, and opens saved contact details from message headers.
- Keeps the latest call or message visible after selection and refresh.

## 한국어

- Mac 알림에 패키지명 대신 Galaxy 앱의 일반 이름을 표시합니다.
- macOS가 지원하는 경우 캐시된 Galaxy 앱 아이콘을 알림 첨부로 표시합니다.
- 알림 설정과 Galaxy 현재 알림에서 앱별 Mac 알림을 영구적으로 켜고 끌 수 있습니다.
- SMS 전송 진행 상태와 중복 전송 방지를 추가하고 문자 상단에서 저장된 연락처 상세로 이동합니다.
- 선택과 새로고침 뒤 최신 통화 또는 메시지가 바로 보이도록 유지합니다.
