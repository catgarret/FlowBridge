# Flow Bridge 0.1.5

## English

- Removed physical display power-off because it can interrupt mirroring on Galaxy devices.
- Applies Galaxy Extra dim at maximum strength while keeping the display powered and the Mac stream connected.
- Restores brightness, auto-brightness mode, and the previous Extra dim state after the session.

## 한국어

- Galaxy에 따라 미러링을 끊을 수 있는 실물 화면 전원 끄기 방식을 제거했습니다.
- 화면 전원은 유지하면서 Galaxy 더 어둡게를 최대로 적용해 Mac 미러링을 계속합니다.
- 세션 종료 후 밝기·자동 밝기·기존 더 어둡게 상태를 복원합니다.
