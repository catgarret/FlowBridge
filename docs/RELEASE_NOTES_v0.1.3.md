# Flow Bridge 0.1.3

## English

- Reliably positions call details at the newest call after delayed data loading.
- Reliably positions message conversations at the newest message using a stable bottom anchor.
- Always shows year, month, day, and time in call and message details.

## 한국어

- 데이터가 늦게 불러와져도 통화 상세가 최신 통화 위치로 이동합니다.
- 고정된 하단 기준점을 사용해 문자 대화가 최신 메시지 위치로 이동합니다.
- 통화와 문자 상세에 연·월·일·시각을 항상 표시합니다.
